# Hall of Fame

Ein Standard wird nicht von einer Firma geschrieben. Er wird von dem geschrieben, der
auftaucht.

Alle unten haben ein Issue eröffnet, einen Pull Request geschickt oder Code in einem
der [TigerTag-Repositories](./developers/repositories.md) geschrieben. Manche haben
einen Tippfehler behoben. Manche haben eine Seite umgeschrieben. Manche haben einen
Fehler so präzise gemeldet, dass er am selben Tag behoben wurde. Alles zählt, und
alles steht hier – ein Problem zu melden ist ein Beitrag, keine Beschwerde.

## Mach mit

Es gibt keine Bewerbung, kein Formular und keine Genehmigung. Tu eines davon, und
dein Name landet bei der nächsten Aktualisierung der Liste auf dieser Seite:

| | |
|---|---|
| **Ein Issue eröffnen** | Etwas ist falsch, unklar oder fehlt – in der Dokumentation, einer App, dem Protokoll. Eine präzise Meldung ist mehr wert als eine höfliche. |
| **Einen Pull Request schicken** | Ein Thema auf einmal, auf der Seite, die dafür zuständig ist. [CONTRIBUTING](../CONTRIBUTING.md) hat die Regeln; sie sind kurz. |
| **Übersetzen** | Englisch ist die Quelle, die anderen Sprachen sind abgeleitet. Eine neue Sprache beginnt mit einer einzigen Seite. |
| **Etwas Kompatibles bauen** | Ein Lesegerät, eine App, eine Drucker-Integration, eine Hülle zum Drucken. Sage frei *„kompatibel mit TigerTag“* – keine Erlaubnis, keine Gebühr. |
| **Es kaputt machen und es uns sagen** | Chip, Lesegerät, App-Version, was du getan hast, was es gezeigt hat. Das ist die Meldung, die behoben wird. |

Weitere Wege zu helfen, auch die, die Geld kosten, und die, die nichts kosten,
stehen unter [Das Projekt unterstützen](./support.md).

Suchst du stattdessen die Rangliste der Maker? Das ist die
[TigerSquad](./tigersquad.md) – Level und XP für alle, die mitmachen.
