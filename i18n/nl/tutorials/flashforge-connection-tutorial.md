# FlashForge: verbindingstutorial

FlashForge-printers verbinden alleen via je lokale netwerk — er is geen cloudoptie.
Wat je van het touchscreen nodig hebt, hangt ervan af hoe Tiger Studio de
printer vindt:

- **Gevonden via de netwerkscan:** alleen de **Printer ID** — stap 3.
- **Handmatig toegevoegd:** het **serienummer** en het **IP-adres** (stap 2), plus de
 **Printer ID** (stap 3).

Zie [FlashForge-compatibiliteit](../compatibility/flashforge.md) voor de rest van
de integratie.

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step1.jpg" alt="FlashForge-touchscreen — knop Basic Info" />
<p><strong>Stap 1.</strong> Tik op het hoofdscherm rechtsonder op de knop "Basic Info".</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step2.jpg" alt="FlashForge-touchscreen — pagina Basic Info" />
<p><strong>Stap 2.</strong> Noteer op de pagina Basic Info het Serial No. en het IP Address.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step3.jpg" alt="FlashForge-touchscreen — pagina Network Mode" />
<p><strong>Stap 3.</strong> Kies het tandwielpictogram, tik op "Network Mode" en noteer daarna de Printer ID.</p>
</div>

> **Eén waarde, twee namen.** De printer noemt het *Printer ID*; het formulier van Tiger Studio
> noemt het **Password**. De Printer ID is wat je daar invoert.
