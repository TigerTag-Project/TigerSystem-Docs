# Elegoo Centauri Carbon 2: overschakelen naar LAN-modus

De directe verbinding van Tiger Studio vraagt dat de **LAN Only-modus** op de printer zelf is ingeschakeld — een
eenmalige instelling op het scherm. Zie [Elegoo-compatibiliteit](../compatibility/elegoo.md) voor de rest van de
integratie.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — LAN Only-scherm" />
<p>Kies op het touchscreen Settings → LAN Only. Schakel LAN Only + Access Code in en kies Confirm.</p>
</div>
