# Hall of Fame

Een standaard wordt niet door een bedrijf geschreven. Hij wordt geschreven door wie komt opdagen.

Iedereen hieronder opende een issue, stuurde een pull request of schreef code in een van de
[TigerTag-repositories](./developers/repositories.md). Sommigen herstelden een typfout. Sommigen
herschreven een pagina. Sommigen meldden een bug zo nauwkeurig dat hij dezelfde dag werd
opgelost. Alles telt, en alles staat hier — een probleem melden is een
bijdrage, geen klacht.

## Doe mee aan de strijd

Er is geen aanmelding, geen formulier en geen goedkeuring. Doe een van deze dingen en je
naam komt op deze pagina bij de volgende verversing van de lijst:

| | |
|---|---|
| **Open een issue** | Iets verkeerds, onduidelijks of ontbrekends — in de documentatie, een app, het protocol. Een nauwkeurige melding is meer waard dan een beleefde. |
| **Stuur een pull request** | Eén onderwerp tegelijk, op de pagina die erover gaat. [CONTRIBUTING](../CONTRIBUTING.md) heeft de regels; ze zijn kort. |
| **Vertaal** | Het Engels is de bron, het Frans is afgeleid. Een nieuwe taal begint met één pagina. |
| **Bouw iets compatibels** | Een lezer, een app, een printerintegratie, een behuizing om te printen. Zeg gerust *“compatible with TigerTag”* — geen toestemming, geen vergoeding. |
| **Maak het kapot en vertel het ons** | Chip, lezer, appversie, wat je deed, wat het toonde. Dat is de melding die wordt opgelost. |

Andere manieren om te helpen, ook de manieren die geld kosten en die niets kosten,
staan op [Het project steunen](./support.md).

Zoek je liever de ranglijst van makers? Dat is de [TigerSquad](./tigersquad.md)
— niveaus en XP voor iedereen die meedoet.
