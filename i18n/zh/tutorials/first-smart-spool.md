# 两分钟打造你的第一卷智能线轴

让任何一卷耗材变得智能——**免费，在家里**就能完成，用的是你已经拥有或只需几分钱就能买到的东西。

## 你需要什么

- **任意一部支持 NFC 的智能手机**（它就是读卡器——已经在你的口袋里）
- **一枚空白 NTAG 芯片**——NTAG213、215 或 216，推荐 **25 mm 圆形**
 （在亚马逊、速卖通或本地只要几分钱；不需要任何官方产品）
- **Tiger NFC Connect**，免费应用——
 [iOS 和 Android 下载](https://tigersystem.io/download)

> 已经买过 Rosa3D、eSun、Sunlu、R3D 等品牌的耗材？你的线轴可能
> **已经带有 TigerTag 芯片**——跳过表单，直接点“扫描”即可。

## 步骤

**你要轻触芯片两次：** 一次开始，一次写入。

1. **安装 Tiger NFC Connect** 并打开它。
2. **点“扫描”**，把手机贴近你的空白芯片。应用读取它，发现它是空的，并提议为它创建一个耗材。
3. **描述你的耗材**——选择材料、颜色、外观、重量等等。选项来自共享的产品库，因此你的线轴会被每一个兼容的应用以完全相同的方式理解。这是一份很快的表单；无需凭记忆输入任何东西。
4. **点“制作”，然后再次把手机贴近芯片。** 第二次轻触就是写入。一秒钟后，数据就**写进了芯片本身**——你的线轴现在知道自己是什么了。
5. **把芯片贴到线轴上。**

### 一卷线轴上的两枚芯片——“Dual NFC”

出厂线轴带有**两枚芯片，分布在相对的两侧**，这样总有一枚芯片正对着读卡器
（[为什么是两枚？](../concepts/tigertag-chip.md)）。你也可以在一次会话中做到同样的事：

1. 扫描第一枚空白芯片，并像上面那样填写表单。
2. 写入之前，**点“Dual NFC”按钮**。
3. 像往常一样**点“制作”**——但现在应用会依次要求这两枚芯片：先是**制作 1/2**，再是**制作 2/2**。两枚芯片最终携带相同的身份。

> **务必从你扫描的那枚芯片开始。** 开启创建流程的那枚芯片，就是应用预期的 1/2；另一枚芯片作为 2/2 随后写入。

就这样。随时可以用离你最近的读卡器重新扫描线轴：**任何一部 NFC 手机**轻触一下，或者把它放在连接到
[Tiger Studio Manager](../products/tiger-studio.md) 的读卡器（ACR122U /
[TigerPOD](../products/tigerpod.md)）上——无论哪种方式，线轴都会自我介绍。
以上全部操作都**100 % 离线**——无需账号，无需云，无需花钱。

## 可选：加入你的库存

想把这卷线轴放进你同步的库存（在桌面端可见，可与好友分享）吗？在应用提示时明确选择即可——这是一个明确的选择，绝不会自动发生。
