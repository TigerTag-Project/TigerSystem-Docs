# Bambu Lab X1 / X1E / H2 / P2 系列：切换到局域网模式

适用于 P2S、X1 Carbon、X1E、X2D、H2S、H2D、H2D Pro 和 H2C——在打印机上启用 **LAN Only 模式**和 **Developer
Mode**，然后在 Tiger Studio 中使用其 IP 地址、序列号和
访问码添加。其他系列和云端选项请参见 [Bambu Lab 兼容性](../compatibility/bambu-lab.md)。

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step1.jpg" alt="X1 系列——设置页面" />
<p><strong>第 1 步。</strong>在打印机端启用 LAN Only 模式。从打印机屏幕左侧进入 Settings 页面，然后点击 Settings。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step2.jpg" alt="X1 系列——LAN Only 入口" />
<p>点击“LAN Only”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step3.png" alt="X1 系列——启用 LAN Only 模式" />
<p>启用 LAN Only 模式。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step4.png" alt="X1 系列——局域网模式实时画面" />
<p>根据你的需要，选择是否启用局域网模式实时画面（LAN mode liveview）。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step5.jpg" alt="X1 系列——Developer Mode 入口" />
<p><strong>第 2 步。</strong>在打印机端启用 Developer mode。启用“Developer Mode”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step6.png" alt="X1 系列——重要提示与风险警告" />
<p>请仔细阅读 Important Notice 和风险警告。如果你接受所有相关风险或后果，请勾选“I confirm reading and understanding the Important Notice above”，然后选择“Enable Developer Mode”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step7.png" alt="X1 系列——Developer Mode 已启用" />
<p>启用此功能后，按钮会变成绿色。然后在 Tiger Studio 中使用打印机的 IP 地址、序列号（Serial Number）和访问码（Access Code）。</p>
</div>
