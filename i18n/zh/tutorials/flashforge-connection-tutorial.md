# FlashForge：连接教程

FlashForge 打印机只能通过本地网络连接——没有云端
选项。需要从触摸屏上获取哪些信息，取决于 Tiger Studio 如何找到
打印机：

- **通过网络扫描找到：** 只需 **Printer ID**——第 3 步。
- **手动添加：** **序列号**和 **IP 地址**（第 2 步），加上
 **Printer ID**（第 3 步）。

其余集成内容请参见 [FlashForge 兼容性](../compatibility/flashforge.md)。

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step1.jpg" alt="FlashForge 触摸屏——Basic Info 按钮" />
<p><strong>第 1 步。</strong>在主界面上，点击屏幕右下角的“Basic Info”按钮。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step2.jpg" alt="FlashForge 触摸屏——Basic Info 页面" />
<p><strong>第 2 步。</strong>在 Basic Info 页面中，记下 Serial No. 和 IP Address。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step3.jpg" alt="FlashForge 触摸屏——Network Mode 页面" />
<p><strong>第 3 步。</strong>点击齿轮图标，再点击“Network Mode”，然后记下 Printer ID。</p>
</div>

> **一个值，两个名称。** 打印机称之为 *Printer ID*；Tiger Studio 的
> 表单称之为 **Password**。在那里输入的就是 Printer ID。
