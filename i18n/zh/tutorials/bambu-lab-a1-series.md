# Bambu Lab A1 系列：切换到局域网模式

适用于 A1 mini、A1 和 A2L——在打印机上启用 **LAN Only Mode** 和 **Developer Mode**，
然后在 Tiger Studio 中使用其 IP 地址、序列号和访问码添加。其他系列和云端选项请参见
[Bambu Lab 兼容性](../compatibility/bambu-lab.md)。

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step1.jpg" alt="A1 系列——设置页面" />
<p><strong>第 1 步。</strong>在打印机端启用 LAN Only Mode。在打印机屏幕上点击 Setting 进入设置页面。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step2.jpg" alt="A1 系列——LAN Only Mode 入口" />
<p>点击“LAN Only Mode”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step3.jpg" alt="A1 系列——启用 LAN Only Mode" />
<p>启用“LAN Only Mode”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step4.jpg" alt="A1 系列——Developer Mode 入口" />
<p><strong>第 2 步。</strong>在打印机端启用 Developer Mode。启用“Developer Mode”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step5.jpg" alt="A1 系列——重要提示" />
<p>请仔细阅读 Important Notice。如果你接受所有相关风险或后果，请勾选“I confirm reading and understanding the Important Notice above”，然后选择“Enable”。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step6.jpg" alt="A1 系列——Developer Mode 已启用" />
<p>启用此功能后，按钮会变成绿色。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step7.jpg" alt="A1 系列——打印机 IP 与序列号" />
<p>在打印机设置中查看打印机的 IP 地址和序列号（Serial Number）。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step8.jpg" alt="A1 系列——在 Tiger Studio 中添加打印机" />
<p>在 Tiger Studio 中使用打印机的 IP 地址、序列号（Serial Number）和访问码（Access Code）。</p>
</div>
