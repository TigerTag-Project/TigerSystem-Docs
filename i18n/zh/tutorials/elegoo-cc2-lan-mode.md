# Elegoo Centauri Carbon 2：切换到局域网模式

Tiger Studio 的直连需要在打印机本身上启用 **LAN Only 模式**——这是一次性的屏幕设置。
其余集成内容请参见 [Elegoo 兼容性](../compatibility/elegoo.md)。

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2——LAN Only 界面" />
<p>在触摸屏上，选择“设置”→“LAN Only”。启用 LAN Only + 访问码，然后选择“确认”。</p>
</div>
