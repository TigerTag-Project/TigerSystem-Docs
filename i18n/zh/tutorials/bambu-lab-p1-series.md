# Bambu Lab P1 系列：切换到局域网模式

适用于 P1P 和 P1S——在打印机上启用 **LAN Only 模式**和 **Developer Mode**，然后
在 Tiger Studio 中使用其 IP 地址、序列号和访问码添加。其他系列和云端选项请参见
[Bambu Lab 兼容性](../compatibility/bambu-lab.md)。

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step1.jpg" alt="P1 系列——设置，WLAN" />
<p><strong>第 1 步。</strong>在打印机端启用 LAN Only 模式。进入 Settings 页面并选择 WLAN。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step2.jpg" alt="P1 系列——选择 LAN Only 模式" />
<p>选择 LAN Only 模式。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step3.jpg" alt="P1 系列——确认 LAN Only 模式" />
<p>选择 Yes，启用 LAN Only 模式。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step4.jpg" alt="P1 系列——LAN Only 模式已开启" />
<p>启用 LAN Only 模式后，会显示 ON。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step5.jpg" alt="P1 系列——找到 Developer Mode" />
<p><strong>第 2 步。</strong>在打印机端启用 Developer mode。开启 LAN Only 模式后，点击向下滚动按钮，找到 Developer Mode。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step6.jpg" alt="P1 系列——重要提示" />
<p>选择 Developer Mode，并请仔细阅读 Important Notice。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step7.jpg" alt="P1 系列——启用 Developer Mode" />
<p>如果你接受所有相关风险或后果，请滚动到底部并点击 Enable。</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step8.jpg" alt="P1 系列——Developer Mode 已开启" />
<p>启用 Developer Mode 后，会显示 ON。然后在 Tiger Studio 中使用打印机的 IP 地址、序列号（Serial Number）和访问码（Access Code）。</p>
</div>
