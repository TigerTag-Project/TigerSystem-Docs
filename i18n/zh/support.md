# 支持本项目

应用是免费的。协议是开放的。TigerPOD 的外壳可免费下载，TigerScale 是任何人都可以制作和销售的开源硬件，
而无论你买的是我们的芯片，还是市场上最便宜的 NTAG，芯片都照样工作。

这一切都不会自己付清账单。下面是真正能起作用的方式——以及，既然开放标准的意义就在于你对它不欠任何东西，
哪些你可以放心忽略。如果你还没有开始，请先免费开始：
[零成本起步](./guides/start-for-free.md)。

## 加入 TigerSquad

[TigerSquad](./tigersquad.md) 是项目背后的免费创客社区：从青铜到铂金的等级、你拥有的每一枚 TigerTag 芯片都能获得 XP，
还能在公开墙上占有一席之地。加入不花钱，也不需要任何付款。

## 请维护者喝杯咖啡

TigerSystem 是一个个人开源项目；捐款归其维护者所有，无论捐不捐，应用都保持免费。
[Buy Me a Coffee](https://buymeacoffee.com/benoitl)、
[Ko-fi](https://ko-fi.com/tigersystemio) 或 [PayPal](https://paypal.me/tigersystemio)——
如果你把捐款关联到你的账号，TigerSquad 成员将晋升为金级。
如何关联，请看 [TigerSquad](./tigersquad.md) 页面。

## 如果本来就要买，就买官方部件

协议有意**不与官方芯片绑定**：任何地方买来的空白 NTAG 工作方式完全相同，也没有任何东西会阻止它。
但当你确实需要芯片或读卡器时，购买官方产品是在资助这个标准，而不是某个市场上的商品链接。

- [TigerTag 芯片](./products/tigertag.md)——贴纸和
 补充装载体，来自官方商店或经销商。
- [TigerPOD](./products/tigerpod.md) 电子套件——和你自己采购的是同样的两台读卡器，
 只是印有项目的标志，通常比分开购买零件更便宜。

用通用零件自己造出整个东西**并不是次一等的路径**。它是同一个 Pod、同一个协议、同样的结果。

## 穿上它

**官方帽子**和**短袖 Polo 衫**在
[tigersystem.io/goodies](https://tigersystem.io/goodies)。尺码、价格和
库存都以那个页面为准——由它负责，本页不负责。

这是最没用的帮助方式，也是最显眼的方式，而这恰恰就是重点：创客空间里的一顶帽子，比一个链接更快地说明了这个项目。

## 贡献你所知道的

这里没有任何一项需要花钱，而且其中一些比金钱更有价值。

| | |
|---|---|
| **修正文档** | 每一页都有编辑链接。你改正的一句错话，就是别人不会再被绊倒的一处——见 [CONTRIBUTING](../CONTRIBUTING.md)。 |
| **翻译** | 英文是源语言，法语是衍生版本。第三种语言从一页开始。 |
| **构建兼容的东西** | 读卡器、应用、打印机集成。尽管说*“兼容 TigerTag”*——无需许可，无需付费（[商标政策](../TRADEMARK.md)）。 |
| **让你的名字登上[名人堂](./hall-of-fame.md)** | 每一个 issue 和每一个 pull request 都会列在那里。无需申请，无需审批。 |
| **报告出问题的地方** | 一份精确的 bug 报告——芯片、读卡器、应用版本、你做了什么、它显示了什么——就是一份贡献。 |
| **给你的线轴贴上标签，并说出来** | 采用率就是论据。每一卷贴了标签的线轴，以及每一位向供应商询问此事的制造商，推动这个标准前进的力度都超过我们自己。 |

## 去问你的耗材品牌

任何人为这个项目做过的最有用的一件事，就是问耗材制造商为什么他们的线轴没有贴标签。
如今有六个品牌在工厂里就出货带 TigerTag 的线轴（[登记册](./certified-partners.md)）；
每一个都是从客户的询问开始的。
