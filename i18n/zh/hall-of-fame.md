## 加入战斗

没有申请，没有表单，也没有审批。只要做到下面任何一项，你的名字就会在下次名单刷新时出现在这一页：

| | |
|---|---|
| **提交 issue** | 任何错误、含糊或缺失之处——文档、应用、协议中的都可以。一份精确的报告比一份客气的报告更有价值。 |
| **发送 pull request** | 一次只处理一个主题，改在负责该主题的那一页上。[CONTRIBUTING](../CONTRIBUTING.md) 里有规则；很短。 |
| **翻译** | 英文是源语言，法语是衍生版本。一种新语言从一页开始。 |
| **构建兼容的东西** | 读卡器、应用、打印机集成、可打印的外壳。尽管说*“兼容 TigerTag”*——无需许可，无需付费。 |
| **把它弄坏，然后告诉我们** | 芯片、读卡器、应用版本、你做了什么、它显示了什么。这样的报告才会被修复。 |

其他帮助的方式，包括花钱的和不花钱的，都在[支持本项目](./support.md)中。

想找创客排行榜？那是 [TigerSquad](./tigersquad.md)——为每一位加入者提供等级和 XP。
