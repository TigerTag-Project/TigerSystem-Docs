# 指南

以任务为导向的操作指南（比
[教程](../tutorials/README.md)更简短、更有针对性）。

## 现有指南

- **[从零开始](./start-for-free.md)** — 为什么看得见的
  部分只占最小的一块，以及你手头已有的东西如何取代
  那些看似必不可少的一切。
- **[当一卷线轴的两枚芯片被读成两卷线轴](./twin-tag-pair.md)** — 一个
  就能定论的测试，为什么两次分开的写入永远无法组成
  一对，以及如何把两枚芯片重写为一对。
- **[将 AI 助手连接到你的账号](./connect-an-ai-assistant.md)** —
  让 Claude、ChatGPT 或任何 MCP 客户端读取你的线轴、货架和打印机，
  并随时切断它对你账号的访问。
- **[耗材材料指南](./filament-materials-guide.md)** — 21 种材料，使用 TigerTag 的名称和 ID：强度、耐化学性、耐热、抗冲击和抗紫外线性能、温度、干燥和密度。
