# Дорожная карта

## Направление развития экосистемы

Высокоуровневые намерения без дат (подробности — на страницах продуктов):

- **Мультивендорный RFID → TigerData** — извлекать данные из меток производителей
 (Bambu Lab, Creality, Elegoo, Anycubic, Snapmaker, Qidi, OpenSpool)
 и преобразовывать их в цифровые катушки TigerData, чтобы филамент других брендов можно
 было сканировать и вести в экосистеме; спецификации только для чтения уже
 описаны ([совместимость](../compatibility/README.md)). Прямое
 декодирование в приложении намеренно не интегрируется, пока не определена модель
 взаимодействия.
- **Больше интеграций принтеров** — Klipper/Moonraker как следующий естественный
 транспорт ([страница Klipper](../compatibility/klipper.md)).
- **Карта дистрибьюторов** *(запланирована)* — число официальных дистрибьюторов растёт
 за пределами [Atome3D](https://atome3d.com); карта покажет, где локально купить
 чипы TigerTag.
- ~~Переносимый файл `.ttag`~~ — **выпущен** в Tiger Studio v2.14.0:
 [формат `.ttag`](../developers/ttag-format.md) (экспорт + импорт, все
 три уровня катушек).
- **TigerTag для смол** — расширение протокола на контейнеры со смолой для
 смоляных 3D-принтеров, приносящее ту же открытую идентичность целому второму
 семейству машин.
- **Развитие TigerHub** — сайт экосистемы
 [tigersystem.io](https://tigersystem.io): более богатые функции социальной песочницы
 (списки желаний, друзья, обмен).
- **Документация** — заполнить заглушки TODO в этом репозитории (руководства,
 гайды, подключение производителей, краткое описание нагрузки RFID).
- **Языки документации** — вики
 [wiki.tigersystem.io](https://wiki.tigersystem.io) выходит сначала на **английском и
 французском**: английский — источник истины, французский выводится из него и
 проходит проверку. Когда оба будут завершены и страницы перестанут меняться,
 последуют остальные локали [tigersystem.io](https://tigersystem.io) —
 **немецкий, испанский, итальянский, польский, китайский и португальский в обоих
 вариантах — бразильском и европейском**, которые экосистема считает двумя отдельными
 локалями, — чтобы документация соответствовала остальной экосистеме.
 Добавлять их раньше значило бы поддерживать девять копий страниц, которые ещё
 пишутся.
- **Помимо текущих локалей** — список не ограничен тем, что
 [tigersystem.io](https://tigersystem.io) обслуживает сегодня. **Японский, корейский и
 русский** — сильнейшие кандидаты после него: во всех трёх есть активные сообщества мейкеров,
 и во всех трёх техническая документация только на английском — настоящий барьер, а не
 небольшое неудобство. Русский к тому же распространён далеко за пределами России.
 Заметьте, что язык может быть достоин документирования, даже там, где магазин не может
 доставлять, — протокол открыт, подойдёт любой чистый чип NTAG, и ничто в экосистеме
 не требует что-либо покупать.

 Какие языки действительно будут добавлены, следует решать по собственному трафику вики,
 когда он появится, а не наугад. Не обязательно и добавлять всё или ничего по каждому языку:
 пользовательские разделы (руководства, FAQ,
 продукты, совместимость) заслуживают перевода намного раньше, чем
 [`developers/`](../developers/README.md), читатели которого и так работают
 на английском.
