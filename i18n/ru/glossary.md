# Глоссарий

Все термины, которые эта документация использует без пояснений. Определения
взяты со страниц, ссылки на которые даны рядом, — у каждой статьи есть
страница, где изложена полная история.

> **Примечание:** этот глоссарий — **заготовка**. Он охватывает термины,
> которые уже встречаются в этом репозитории; он намеренно неполон, а статьи
> добавляются, только когда где-то в документации появляется содержание для
> них. Не хватает термина? Добавьте его со ссылкой на страницу, которая его
> определяет.

## Собственный словарь экосистемы

| Термин | Значение |
|---|---|
| **TigerSystem** | Вся открытая экосистема: формат чипа, справочные данные, приложения, оборудование и облачная часть. См. [Почему существует TigerSystem](./vision/why-tigersystem.md). |
| **TigerTag** | Стандартный NFC-чип NTAG с открытой полезной нагрузкой TigerTag в 144 байта — идентичность катушки, которую может прочитать что угодно. См. [TigerTag](./products/tigertag.md). |
| **TigerTag+** | TigerTag, идентичность которого содержит **ID продукта из официального каталога**, а также необязательные обогащающие данные, предоставляемые метаданными Web API. Чип по-прежнему на 100% читается офлайн. Знак `+` означает *идентифицирован*, а не *сертифицирован*. См. [TigerTag+](./products/tigertag-plus.md). |
| **TigerTag+ Certified** | TigerTag+, который дополнительно несёт криптографическую **подпись**, записанную производителем, у которого есть сертификация и инструменты для подписи. Проверка такой подписи бесплатна и работает офлайн; выдача подписи — это то, что даёт сертификация. |
| **TigerData** | Та же идентичность вообще без чипа: данные протокола в чисто цифровом виде, без UID, с возможностью в любой момент перенести на настоящий чип. См. [Одна идентичность, четыре состояния](./concepts/universal-filament-identity.md). |
| **TigerData+** | Катушка без чипа, которая несёт реальный продукт из официального каталога — точные бренд, цвет, материал, температуры, диаметр, SKU и EAN — вместо значений, введённых вручную. Знак `+` означает *идентифицирован*, а не *сертифицирован*. |
| **Official** | Сделано самой TigerSystem — чипы обоих форм-факторов, а также приложения и оборудование из раздела [Продукты](./products/README.md). Это указание на происхождение, а не присваиваемый знак: TigerSystem не сертифицирует саму себя. |
| **TigerTag Compatible** | Бесплатный уровень: всё, что *работает с* чипами TigerTag — считыватели, приложения, принтеры, слайсеры, инструменты. Разрешение не требуется ни на реализацию, ни на заявление об этом, ни на показ логотипа в приложении, документации или карточке магазина. Он охватывает и **TigerTag+**: проверка подписи бесплатна, работает офлайн и без ограничений. Одно слово он не включает никогда — *certified*. |
| **TigerTag Certified** | Уровень с аудитом, открытый для всего, что создаёт третья сторона — устройства, приложения, филамента, инлея, носителя — после прохождения аудита на соответствие требованиям. Присваивается, а не заявляется, вносится в реестр сертифицированных и может быть отозван. Существует в двух областях: **TigerTag Certified** и **TigerTag+ Certified**. Сертифицированные партнёры могут наносить знак **на продукт** и выдавать подписи TigerTag+. См. [Документация для разработчиков](./developers/README.md) и [критерии сертификации](https://github.com/TigerTag-Project/TigerTag-RFID-Guide/blob/main/CERTIFICATION.md). |
| **Tiger NFC Connect** | Мобильное приложение (iOS/Android) — приложите, чтобы прочитать, приложите, чтобы записать, просматривайте каталог. Прежнее название — «TigerTag RFID Connect». См. [Tiger NFC Connect](./products/tiger-nfc-connect.md). |
| **Tiger Studio** | Настольное приложение с открытым исходным кодом (Windows/macOS/Linux) — инвентарь, стеллажи, датчики и связи с принтерами. См. [Tiger Studio](./products/tiger-studio.md). |
| **TigerHub** | Веб-дом экосистемы на `tigersystem.io` — витрина, списки желаний, коды друзей, публичный обмен списками. См. [TigerHub](./products/tigerhub.md). |
| **TigerPOD** | Подставка для двойного NFC-считывателя, печатаемая на 3D-принтере, — STL бесплатно. См. [TigerPOD](./products/tigerpod.md). |
| **TigerScale** | Весы для филамента на ESP32 с открытым исходным кодом, отвечающие на вопрос «сколько осталось?». См. [TigerScale](./products/tigerscale.md). |
| **TigerSpool** | Коробка рядом с принтером, которая при контакте записывает идентичность катушки в слот принтера — без приложения, без клавиатуры, любой бренд. См. [TigerSpool](./products/tigerspool.md). |
| **TigerTag Factory / Manager** | Промышленный набор инструментов производственного уровня, программирующий чипы на линиях производства филамента, и инструменты, ведущие базу данных филаментов. Непубличные. См. [Набор Factory](./products/factory-suite.md). |
| **Carrier** | Полоса, несущая два чипа катушки — по одному на каждом сложенном конце, приклеенная к картонной втулке промышленным клеем 3M. Используется на заводской линии, продаётся отдельно для рефилов, а также публична и доступна для печати дома. См. [Чип TigerTag](./concepts/tigertag-chip.md). |
| **Masterspool** | Многоразовая бобина, на которую монтируется рефил без катушки. Чип рефила находится внутри картонной втулки, поэтому остаётся с филаментом, а не с бобиной. |
| **Twin Tag** | Два чипа одной катушки, записанные вместе как пара и остающиеся идентичными на протяжении всей жизни катушки — всегда считаются **одной** катушкой. |
| **Справочная база данных** | Общие таблицы ID (бренды, материалы, аспекты, типы, диаметры, единицы), раздаваемые с `cdn.tigertag.io`, чтобы чип, закодированный одним инструментом, читался одинаково в любом другом. См. [Универсальная идентичность филамента](./concepts/universal-filament-identity.md). |
| **Aspect** | Поле справочной базы данных, описывающее цвет и отделку филамента; [образец материала](./developers/material-swatch.md) рисуется по нему. |
| **Образец материала** | Нормативное соглашение о превращении *данных* о цвете катушки в одну и ту же *картинку* на любой поверхности — три формы (мягкое разделение под 135° для 2–3 жёстких цветов, «камамбер» для 4+, плавный градиент под 135° для плавных цветов) с эталонным рендерером для проверки реализации. См. [Образец материала](./developers/material-swatch.md). |
| **Файл `.ttag`** | Переносимый офлайн-файл обмена, несущий один или несколько материалов инвентаря (TigerData, TigerData+, TigerTag или TigerTag+) между инструментами. См. [формат `.ttag`](./developers/ttag-format.md). |
| **Вторая жизнь** | Перекодирование чипа для рефиллированной или перепрофилированной катушки либо его преобразование в обычный NDEF для любого другого применения NFC — чип никогда не должен становиться электронным мусором. См. [Вторая жизнь](./philosophy/second-life.md). |
| **Мост через смартфон** | Использование телефона (или настольного считывателя) для идентификации катушки для принтера, у которого нет собственного RFID-считывателя. См. [Мост через смартфон](./philosophy/smartphone-bridge.md). |
| **Связь с принтером** | Tiger Studio общается с машиной по локальной сети — телеметрия, слоты филамента, задание, камера. Отличается от чтения собственных тегов производителя. См. [Совместимость](./compatibility/README.md). |
| **Рефил** | Моток филамента, продаваемый без бобины, чтобы смонтировать его на уже имеющуюся у вас катушку. |

## NFC и RFID

| Термин | Значение |
|---|---|
| **NFC** | Near-Field Communication — радиосвязь малого радиуса действия, которой может пользоваться любой современный смартфон, чтобы прочитать TigerTag. |
| **RFID** | Radio-Frequency Identification — более широкое семейство, к которому относится NFC. Здесь так называют и собственные закрытые теги катушек производителей, и TigerTag. |
| **NTAG213 / 215 / 216** | Семейство чипов NXP, которое использует TigerTag (NFC Forum Type 2). Полезная нагрузка рассчитана так, чтобы помещаться в самый маленький, NTAG213; официальные фирменные чипы — NTAG215, чтобы оставить запас памяти для повторного использования. См. [Чип TigerTag](./concepts/tigertag-chip.md). |
| **NDEF** | NFC Data Exchange Format — стандартный контейнер, в котором хранится полезная нагрузка TigerTag; поэтому её может прочитать любой NFC-инструмент, а чип пустой катушки можно превратить в обычный NFC-объект. |
| **UID** | Уникальный аппаратный идентификатор чипа, задаваемый при изготовлении и не перезаписываемый. К нему привязана резервная копия чипа, а также подпись TigerTag+ Certified. |
| **Mifare Classic / Mifare Ultralight** | Семейства чипов, которые производители принтеров используют для собственных тегов катушек, — описаны по производителям в [матрице совместимости](./compatibility/README.md). |
| **ACR122U** | Класс обычных USB NFC-считывателей, используемых для чтения и записи чипов с компьютера; [TigerPOD](./products/tigerpod.md) — это подставка, построенная вокруг такого считывателя. |
| **PN532 / RC522** | Дешёвые модули NFC-считывателей, обычно в паре с ESP32, для самодельных считывателей — подход, который использует [TigerScale](./products/tigerscale.md). |
| **ECDSA** | Схема подписи, которую проверяет необязательное расширение `verify` Python SDK, — механизм, стоящий за подписью происхождения TigerTag+. См. [SDK](./developers/sdks.md). |
| **OpenSpool** | Независимый открытый стандарт NFC-тегов для катушек (NFC Type 2, NDEF JSON, без блокировки). См. [OpenSpool](./compatibility/openspool.md). |
| **OpenRFID** | Общественный набор инструментов RFID для нескольких производителей, на котором основаны листы декодирования по производителям и который читает TigerTag. См. [Сторонние интеграции](./developers/integrations.md). |

## Принтеры и оборудование

| Термин | Значение |
|---|---|
| **AMS** | Automatic Material System от Bambu Lab — многокатушечный податчик. Важна здесь потому, что обычно делит один RFID-считыватель на два слота, из-за чего у катушки два чипа. |
| **CFS** | Creality Filament System — мультиматериальный модуль Creality. |
| **ACE** | Мультиматериальный модуль Anycubic. |
| **Canvas** | Мультиматериальный модуль Elegoo. |
| **IFS** | Мультифиламентная система FlashForge — поле в её протоколе по-прежнему называется `matlStation`. |
| **MMU** | Multi-Material Unit — общий термин для дополнения, подающего несколько филаментов на один принтер (ERCF, MMU2, Box Turtle… в мире Klipper). См. [Klipper](./compatibility/klipper.md). |
| **Klipper / Moonraker** | Открытая прошивка принтеров и её API — WebSocket Moonraker является транспортом, который уже использует связь Snapmaker, и следующим естественным для машин на Klipper. См. [Klipper](./compatibility/klipper.md). |
| **HID Scale** | Стандартный USB-протокол для весов (серия DYMO M и совместимые), который Tiger Studio читает нативно как стороннюю альтернативу TigerScale. |
| **TD / TD-1 / TD1s** | **Transmission Distance** — сколько света пропускает филамент, значение, на которое опираются HueForge и полноспектральная печать, — и анализатор [AJAX-3D](https://ajax-3d.com), который его измеряет, в самодельном (TD-1) и собранном (TD1s) вариантах. Измеренный TD можно хранить прямо в протоколе TigerTag. См. [Стороннее оборудование](./compatibility/third-party-hardware.md). |
| **ESP32** | Обычный микроконтроллер, на котором построены TigerScale и большинство самодельных считывателей TigerTag. |

## Облако и данные

| Термин | Значение |
|---|---|
| **Firebase / Firestore** | Обычный сервис Google, в котором размещены аккаунты и инвентари, — одна общая база данных, которую читают и в которую пишут все приложения, а соблюдение правил обеспечивают серверные правила безопасности. См. [Инвентарь и облачная синхронизация](./concepts/inventory-and-cloud-sync.md). |
| **`cdn.tigertag.io`** | Откуда раздаётся общая справочная база данных. |
| **Код друга / ссылка на список** | Два способа поделиться инвентарём — принятый друг или публичная ссылка только для чтения, которую любой открывает в браузере, без приложения и без аккаунта. См. [TigerHub](./products/tigerhub.md). |
| **SKU / EAN** | Код продукта производителя и номер его штрихкода — то, что несёт TigerData+, чтобы точно указать, какой именно продукт каталога представляет катушка. |
