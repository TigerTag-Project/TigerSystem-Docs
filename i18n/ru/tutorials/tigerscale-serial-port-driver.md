# Как заставить COM-порт появиться для прошивки TigerScale V3

TigerScale V3 использует чип **ESP32-S3**. Чтобы прошить микропрограмму, компьютер должен видеть плату как **COM-порт / последовательный порт**.

На большинстве современных компьютеров этот порт появляется **сам**, когда вы подключаете плату.
Если в программе прошивки порт не появился, не хватает небольшого драйвера: следуйте разделу для вашей системы ниже.

> **Прежде чем начать**
> - Используйте настоящий **USB-кабель для передачи данных** (некоторые кабели только заряжают и не передают данные).

## macOS — ничего устанавливать не нужно

Драйвер не требуется.
Подключите плату, откройте программу прошивки, и плата сразу появится в списке. Выберите её и начните прошивку.

Если она не появилась: замените USB-кабель и попробуйте снова.

## Windows — установите драйвер (если COM-порт не появился)

Если в программе прошивки нет порта, не хватает USB-драйвера Espressif. Вот как
его установить, шаг за шагом:

1. **Скачайте утилиту** — нажмите эту ссылку, она скачает `idf-env.exe` прямо
 с сервера Espressif (по умолчанию файл окажется в папке **Загрузки**):
 **[https://dl.espressif.com/dl/idf-env/idf-env.exe](https://dl.espressif.com/dl/idf-env/idf-env.exe)**
2. **Откройте PowerShell от имени администратора** — нажмите меню **Пуск**, введите
 `powershell`, щёлкните правой кнопкой **Windows PowerShell** и выберите **Запуск от
 имени администратора**.
3. **Скопируйте эту единственную строку, вставьте её в PowerShell и нажмите Enter:**

 ```powershell
 cd $env:USERPROFILE\Downloads; .\idf-env.exe driver install --espressif
 ```

 > Сохранили файл не в Загрузки? Замените только
 > `$env:USERPROFILE\Downloads` на эту папку — например
 > `C:\Users\yourname\Desktop`. Остальная часть строки остаётся прежней.

4. Дождитесь завершения (несколько секунд).
5. **Отключите и снова подключите плату.**
6. Снова откройте программу прошивки: порт (например, `USB JTAG/serial debug unit (COM3)`) теперь должен появиться.

> Скачивая утилиту самостоятельно, а не вставляя однострочную команду, которая
> загружает и запускает исполняемый файл с правами администратора, вы можете увидеть,
> что именно собираетесь запустить и откуда оно взято. Это всего один лишний щелчок.

✓ Выберите этот порт и начните прошивку.

## Linux — предоставьте доступ к последовательному порту

Порт обычно появляется сам (`/dev/ttyACM0`), но вашему пользователю нужно разрешение на доступ к нему.

1. Откройте **терминал**.
2. Добавьте себя в группу, управляющую последовательными портами:

 ```bash
 sudo usermod -aG dialout $USER
 ```

3. **Выйдите из системы и войдите снова** (или перезагрузитесь), чтобы изменение вступило в силу.
4. Снова подключите плату и заново откройте программу прошивки.

> Совет: если вы используете программу прошивки **в браузере** (Web Serial), применяйте **Google Chrome** или **Microsoft Edge**; Firefox эту функцию не поддерживает.

## Всё равно не работает

- **Замените USB-кабель** (проблема №1: кабель «только для зарядки»).
- Попробуйте **другой USB-порт** компьютера (лучше прямой, а не через хаб).
- В Windows откройте **Диспетчер устройств**: если вы видите устройство с жёлтым восклицательным знаком, драйвера не хватает → повторите раздел для Windows выше.
- Чтобы принудительно включить режим прошивки: удерживайте кнопку **BOOT**, один раз нажмите **RESET**, затем отпустите **BOOT** и попробуйте снова.
