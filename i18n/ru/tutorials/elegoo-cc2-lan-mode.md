# Elegoo Centauri Carbon 2: переключение в режим LAN

Для прямого подключения Tiger Studio на самом принтере должен быть включён **режим LAN Only** — это разовая настройка на экране. Об остальной части интеграции читайте в разделе [Совместимость с Elegoo](../compatibility/elegoo.md).

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — экран LAN Only" />
<p>На сенсорном экране выберите Settings → LAN Only. Включите LAN Only + Access Code и нажмите Confirm.</p>
</div>
