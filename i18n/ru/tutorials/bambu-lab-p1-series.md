# Bambu Lab серии P1: переключение в режим LAN

Для P1P и P1S — включите на самом принтере **режим LAN Only** и **Developer Mode**, затем
добавьте его в Tiger Studio, указав IP-адрес, серийный номер и код доступа. О других сериях
и облачном варианте читайте в разделе
[Совместимость с Bambu Lab](../compatibility/bambu-lab.md).

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step1.jpg" alt="Серия P1 — Settings, WLAN" />
<p><strong>Шаг 1.</strong> Включите режим LAN Only на стороне принтера. Откройте страницу Settings и выберите WLAN.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step2.jpg" alt="Серия P1 — выбор режима LAN Only" />
<p>Выберите режим LAN Only.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step3.jpg" alt="Серия P1 — подтверждение режима LAN Only" />
<p>Выберите Yes и включите режим LAN Only.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step4.jpg" alt="Серия P1 — режим LAN Only включён" />
<p>После включения режима LAN Only отобразится ON.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step5.jpg" alt="Серия P1 — поиск Developer Mode" />
<p><strong>Шаг 2.</strong> Включите Developer Mode на стороне принтера. После включения режима LAN Only нажмите кнопку Scroll Down и найдите Developer Mode.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step6.jpg" alt="Серия P1 — Important Notice" />
<p>Выберите Developer Mode и внимательно прочитайте Important Notice.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step7.jpg" alt="Серия P1 — включение Developer Mode" />
<p>Если вы принимаете все связанные риски и последствия, прокрутите до конца и нажмите Enable.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step8.jpg" alt="Серия P1 — Developer Mode включён" />
<p>После включения Developer Mode отобразится ON. Затем используйте IP-адрес принтера, Serial Number и Access Code в Tiger Studio.</p>
</div>
