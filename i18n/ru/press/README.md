# Пресс-кит

Медиаматериалы для статей, видео и публикаций о **TigerSystem** и
**TigerTag** — логотипы, изображения продуктов, настоящие фотографии и утверждённые
формулировки, готовые к публикации.

фона, для которого он предназначен. Большинство знаков существуют в версии для **тёмного фона** и для
**светлого фона** — контурные знаки **всегда предназначены для светлых

Именование: знаки **TigerTag** содержат надпись TIGER TAG; знаки только с головой — это
ресурсы **Tiger**. Каждое семейство бейджей существует в трёх вариантах кадрирования — квадратном, вписанном,
с выходом за края — и представляет собой точно тот рисунок, который напечатан на коробках
партнёров. Белые знаки — одноцветные векторы для тёмных поверхностей; чёрные **контурные** знаки всегда
предназначены для светлых фонов. **Иконки приложения TigerSystem** имеют собственный тёмный
фон.

## TigerScale

|| |
|---|---|
| <img src="../assets/tigerscale-v3.webp" alt="TigerScale V3 — цветной сенсорный экран, два NFC-считывателя PN532" /> | <img src="../assets/tigerscale-at-home.jpg" alt="TigerScale V3 на верстаке мейкера, на нём лежит катушка" /> |

**TigerScale V3**, текущее поколение: студийный снимок и
**иллюстрация** тех же весов на верстаке мейкера — вторая является
рендером, а не фотографией, поэтому, пожалуйста, указывайте это при публикации.
ESP32-S3, цветной сенсорный экран 3,5″, два считывателя PN532, так что
[катушка с двойной меткой](../concepts/tigertag-chip.md) определяется в любом положении.
Открытое оборудование, MIT.

Предыдущие поколения описаны на [странице продукта](../products/tigerscale.md);
более старая фотография, [`tigerscale-photo.jpg`](../assets/tigerscale-photo.jpg),
сохранена только для архива — пожалуйста, не используйте её сегодня для
иллюстрации продукта.
