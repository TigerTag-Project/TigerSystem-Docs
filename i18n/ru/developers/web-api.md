# Web API

## Для чего он нужен

TigerTag несёт всё, что нужно принтеру, **на чипе, офлайн**. Web
API существует для того, что чип вместить не может и что меняется после записи:
технические паспорта, документы по безопасности, фото, видео,
исправления производителя.

Это **одна HTTP-точка доступа для всего филамента всех брендов** — без ключа, без
аккаунта, без регистрации, без переговоров об условиях использования. Вы подаёте идентификатор продукта —
получаете продукт.

```
https://api.tigertag.io/api:tigertag/product/get?uid=0&product_id=<ID>&lang=en
```

Параметр `lang` выбирает язык текстовых полей.

## Что возвращается

Четыре реальных продукта четырёх разных брендов через один и тот же адрес:

| `product_id` | Продукт | Возвращаемые документы |
|---|---|---|
| `10` | Polymaker PolyTerra™ PLA | MSDS · TDS · советы · видео |
| `30` | R3D PLA High Speed | пищевой контакт · MSDS · REACH · RoHS · TDS · видео |
| `40` | Sunlu PLA Matte | MSDS · REACH · RoHS · TDS · видео |
| `50` | eSun PLA+ | пищевой контакт · MSDS · REACH · RoHS · TDS · советы · видео |

Каждый ответ содержит идентичность (бренд, серию, название, SKU, EAN, цвет),
полный профиль печати (сопло, стол, сушилка, вентилятор, диаметр, вес, shore,
transmission distance), фото продукта и блок `links` выше —
`tds`, `msds`, `rohs`, `reach`, `en71`, `food`, `tips`, `youtube`.

## Почему он поддерживает TigerTag+ в актуальном состоянии

[TigerTag+](../products/tigertag-plus.md) хранит **идентификатор продукта из каталога**,
а не адрес. Идентификатор никогда не истекает и не перемещается, поэтому производитель может
исправить температуру или приложить технический паспорт через полгода после отгрузки катушек,
и каждый считыватель увидит новое значение при следующем чтении — без
перезаписи чего-либо на чипе и без того, чтобы чип когда-либо зависел
от сети при печати.

Поэтому же важна единая точка доступа: один адрес обслуживает все бренды, так что
считыватель реализует его один раз, и он работает для филамента, которого никогда не видел.

## И офлайн тоже — весь каталог это файл

Ничто из сказанного выше не требует, чтобы точка доступа была доступна или даже существовала.

Полный справочник опубликован единым файлом,
[`id_catalog.json`](https://github.com/TigerTag-Project/TigerTag-RFID-Guide/blob/main/database/id_catalog.json) — **каждый идентификатор каждого филамента в базе данных**,
обновляется в течение дня, около 12 МБ, без ключа и без аккаунта. Любой может
скачать его, сделать зеркало, встроить в приложение, положить на NAS мастерской
или носить на USB-накопителе.

Считыватель с такой копией разрешает идентификатор TigerTag+ **вообще без сети**.
Именно поэтому идентификатор надёжнее адреса: адресу нужен отвечающий хост, а общему справочнику достаточно
один раз быть скопированным — и его можно скопировать где угодно на планете, кому угодно и когда угодно.

Web API остаётся более свежим путём, и именно он несёт технические паспорта и
фото. Файл — это опора под ним.

## Чего он никогда не делает

Web API **не может заставить чип работать**, потому что чип и так работает без
него. Прочитайте TigerTag в режиме «в самолёте» — и вы получите бренд, материал, цвет,
диаметр, вес и температуры — всё, что нужно для печати. Web API добавляет вокруг этого документы
и изображения, а поверх — исправления.
