# Account API и интеграция сторонних приложений

## Контракт

Сторонние приложения подключаются к бэкенду TigerSystem — обычному Firebase — по
**стандартной схеме Firebase**:

1. Получите публичную конфигурацию SDK:
 `https://tigertag-cdn.web.app/__/firebase/init.json`
2. `firebase.initializeApp(config)`
3. Аутентифицируйте **собственный аккаунт TigerTag пользователя** (публичность конфигурации
 намеренна — безопасность обеспечивается на стороне сервера правилами Firestore).
4. Читайте и записывайте данные этого пользователя в пределах документированной поверхности.

## Правила безопасности — чего ожидать

- `users/{uid}/**` по умолчанию доступен только владельцу.
- Запись данных другого пользователя всегда требует **предварительной связи** (например,
 принятой дружбы) — открытых путей записи нет.
- Некоторые коллекции работают по **белому списку полей**: запись с полями вне списка
 отклоняется.
- Поля только для администратора (роли, флаги отладки) клиент записать не может никогда.

## HTTP-эндпоинты

`cdn.tigertag.io` находится в **том же проекте Firebase**, что и аккаунты: он
размещает общую справочную базу данных, изображения катушек (включая фотографии продуктов
TigerTag+) и HTTP-эндпоинты, связанные с базой данных TigerSystem.

| Эндпоинт | Назначение |
|---|---|
| `https://cdn.tigertag.io/healthz/` | Проверка работоспособности |
| `https://cdn.tigertag.io/setSpoolWeightByRfid?ApiKey=&uid=&weight=` | Передать вес катушки по UID чипа (используется устройствами класса весов) |
