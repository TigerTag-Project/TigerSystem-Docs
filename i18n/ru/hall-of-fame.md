# Зал славы

Стандарт пишет не компания. Его пишет тот, кто пришёл.

Каждый из перечисленных ниже открыл issue, отправил pull request или написал код в одном из
[репозиториев TigerTag](./developers/repositories.md). Кто-то исправил опечатку. Кто-то
переписал страницу. Кто-то сообщил об ошибке так точно, что она была исправлена в тот же
день. Всё это засчитывается, и всё это здесь — сообщить о проблеме значит
внести вклад, а не пожаловаться.

## Присоединяйтесь к борьбе

Никаких заявок, форм и одобрений. Сделайте любое одно из этого, и ваше
имя окажется на этой странице при следующем обновлении списка:

| | |
|---|---|
| **Откройте issue** | Что-то неверно, неясно или отсутствует — в документации, приложении, протоколе. Точный отчёт ценнее вежливого. |
| **Отправьте pull request** | Одна тема за раз, на странице, которой она принадлежит. Правила изложены в [CONTRIBUTING](../CONTRIBUTING.md); они короткие. |
| **Переведите** | Источник — английский, французский — производный. Новый язык начинается с одной страницы. |
| **Создайте что-то совместимое** | Считыватель, приложение, интеграцию с принтером, корпус для печати. Свободно говорите *«совместимо с TigerTag»* — без разрешения и платы. |
| **Сломайте и расскажите нам** | Чип, считыватель, версия приложения, что вы сделали, что оно показало. Именно такой отчёт и исправляют. |

Другие способы помочь, в том числе платные и бесплатные,
описаны в разделе [Поддержать проект](./support.md).

Ищете рейтинг мейкеров? Это [TigerSquad](./tigersquad.md) —
уровни и XP для всех, кто присоединяется.
