# Anycubic

## Связь с принтером — **Live** (LAN + облако)

| Аспект | Подробности |
|---|---|
| Протокол (LAN) | MQTTS, порт 9883 (TLS 1.2), напрямую к принтеру |
| Протокол (облако) | Подписанный REST + облачный MQTT производителя |
| Филамент | Многоцветный бокс ACE — поддержка по слотам |
| Обнаружение | Зонд `/info`, порт 18910 |
| Камера | Поток FLV (порт 18088) |
| Управление | Живая панель управления (оси, температуры, свет, вентилятор, загрузка/выгрузка) |

> **Примечание:** облачный режим — единственный случай, когда связь с принтером идёт через облако
> производителя; режим LAN остаётся полностью локальным.

## Нативный RFID — спецификация описана, чтение в приложении запланировано

Метки катушек Anycubic — это **Mifare Ultralight** **без аутентификации и без
криптографии** — читаются (и клонируются) тривиально. Спецификация декодирования
(только чтение):
[`docs/rfid-vendors/anycubic.md`](https://github.com/TigerTag-Project/TigerTag-Studio-Manager/blob/main/docs/rfid-vendors/anycubic.md).

## Порядок работы

1. **Добавьте принтер** — двумя путями: **режим LAN** (локальное обнаружение через
 зонд `/info`; учётные данные подключения импортируются из конфигурации слайсера
 производителя) или **облачный режим** через аккаунт Anycubic.
2. **Отсканируйте катушку** — телефоном или настольным считывателем; она попадёт в ваш инвентарь.
3. **Назначьте её слоту ACE** — Tiger Studio сопоставляет катушки из инвентаря
 с многоцветным боксом ACE.
4. **Live и управление** — телеметрия, ход задания, поток с камеры FLV и
 **панель управления**: оси, температуры, свет, вентилятор, загрузка/выгрузка по
 слотам.

## Ограничения

- Нативные метки Anycubic пока не читаются в приложении — спецификация описана, а текущая работа направлена на преобразование данных меток производителей в катушки TigerData (см. [Совместимость](./README.md)).
