# Klipper / Moonraker

## Связь с принтером — пока нет, но основа уже есть

Универсальные принтеры на Klipper (через API **Moonraker**) на сегодня **не имеют
официальной интеграции**. Однако подключение Tiger Studio к Snapmaker уже
использует Moonraker WebSocket/JSON-RPC — это естественная основа для
независимой от производителя интеграции с Klipper.

| Аспект | Статус |
|---|---|
| Транспорт Moonraker | Есть (используется в интеграции Snapmaker) |
| Универсальная поддержка Klipper | Запланирована / объём работ уточняется |
| Сопоставление слотов филамента | Зависит от конфигурации MMU машины — объём работ уточняется |

## Использование TigerTag с Klipper уже сегодня

Работает всё, кроме живой связи с принтером: чипы TigerTag, инвентарь,
отслеживание веса, стеллажи и функции обмена не зависят от принтера.
