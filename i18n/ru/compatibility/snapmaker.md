# Snapmaker

## Связь с принтером — **Live**

| Аспект | Подробности |
|---|---|
| Протокол | Moonraker WebSocket (JSON-RPC), порт 7125 + проприетарные расширения |
| Обнаружение | HTTP-сканирование |
| Филамент | 4 слота — редактирование филамента по слотам (цветовая модель RRGGBBAA) |
| Управление | Живая панель управления (оси, температуры, свет, вентилятор, скорость, загрузка/выгрузка) |
| Телеметрия | Температуры, ход задания |

## Нативный RFID — спецификация описана, чтение в приложении запланировано

Метки катушек Snapmaker — это **Mifare Classic 1K** с **ключами секторов, получаемыми
через HKDF**, и **подписью RSA-2048 PKCS#1 v1.5 + SHA-256** — самый защищённый из
описанных на сегодня форматов. Спецификация декодирования (только чтение):
[`docs/rfid-vendors/snapmaker.md`](https://github.com/TigerTag-Project/TigerTag-Studio-Manager/blob/main/docs/rfid-vendors/snapmaker.md).

## Порядок работы

1. **Добавьте принтер** — HTTP-сканирование в LAN или по IP; Tiger Studio
 работает по Moonraker (JSON-RPC поверх WebSocket).
2. **Отсканируйте катушку** — телефоном или настольным считывателем; она попадёт в ваш инвентарь.
3. **Назначьте её слоту** — редактирование филамента по слотам (цветовая модель
 Snapmaker RRGGBBAA обрабатывается прозрачно).
4. **Live и управление** — телеметрия, ход задания и **панель управления**:
 оси, температуры, свет, вентилятор, режим скорости, загрузка/выгрузка по слотам.

## Ограничения

- Нативные метки Snapmaker пока не читаются в приложении — спецификация описана, а текущая работа направлена на преобразование данных меток производителей в катушки TigerData (см. [Совместимость](./README.md)).

## Первый принтер, нативно читающий TigerTag

Сообщество разработало
[Snapmaker U1 Extended Firmware](https://github.com/paxx12-snapmaker-u1/SnapmakerU1-Extended-Firmware)
(независимая, GPL-3.0): она добавляет SSH, потоковую передачу с камеры, метрики — а вместе с ними
**Snapmaker U1 нативно читает TigerTag прямо на самой машине**. Это
делает U1 первым принтером, где катушка TigerTag распознаётся без
какого-либо приложения посередине — будущее, к которому стремится
[коллективная игра](../vision/for-filament-manufacturers.md), наступило
раньше срока благодаря сообществу. См.
[интеграции сторонних разработчиков](../developers/integrations.md).
