# Гайды

Практические инструкции по конкретным задачам (короче и целенаправленнее,
чем [руководства](../tutorials/README.md)).

## Доступные гайды

- **[Старт за 0 $](./start-for-free.md)** — почему видимые
  детали — самая малая часть и что у вас уже есть вместо всего,
  что выглядит обязательным.
- **[Когда два чипа катушки читаются как две катушки](./twin-tag-pair.md)** —
  один тест, который всё проясняет, почему два отдельных прохода записи никогда не
  образуют пару и как переписать два чипа как один.
- **[Подключите ИИ-ассистента к своему аккаунту](./connect-an-ai-assistant.md)** —
  позвольте Claude, ChatGPT или любому клиенту MCP читать ваши катушки, стеллажи и
  принтеры, и как отключить его от аккаунта.
- **[Руководство по материалам филамента](./filament-materials-guide.md)** — 21 материал под названиями и ID TigerTag: прочность, химическая стойкость, термо-, ударо- и УФ-стойкость, температуры, сушка и плотность.
