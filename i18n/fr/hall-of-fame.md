# Hall of Fame

Un standard ne s'écrit pas dans une entreprise. Il s'écrit avec ceux qui se
présentent.

Toutes les personnes ci-dessous ont ouvert une issue, envoyé une pull request
ou écrit du code dans l'un des
[dépôts TigerTag](./developers/repositories.md). Certaines ont corrigé une
coquille. D'autres ont réécrit une page. D'autres encore ont signalé un bug
avec assez de précision pour qu'il soit corrigé le jour même. Tout cela compte,
et tout cela figure ici — signaler un problème est une contribution, pas une
réclamation.

## Rejoignez le combat

Il n'y a ni candidature, ni formulaire, ni validation. Faites l'une de ces
choses et votre nom apparaîtra sur cette page à la prochaine régénération :

| | |
|---|---|
| **Ouvrir une issue** | Quelque chose de faux, d'obscur ou de manquant — dans la documentation, une application, le protocole. Un signalement précis vaut mieux qu'un signalement poli. |
| **Envoyer une pull request** | Un sujet à la fois, sur la page qui en est propriétaire. [CONTRIBUTING](../CONTRIBUTING.md) contient les règles ; elles sont courtes. |
| **Traduire** | L'anglais est la source, le français en dérive. Une nouvelle langue commence par une seule page. |
| **Construire quelque chose de compatible** | Un lecteur, une application, une intégration imprimante, une coque à imprimer. Dites *« compatible avec TigerTag »* librement — sans autorisation, sans frais. |
| **Le casser, et nous le dire** | Puce, lecteur, version de l'application, ce que vous avez fait, ce qui s'est affiché. C'est ce signalement-là qui est corrigé. |

Les autres façons d'aider, celles qui coûtent de l'argent comme celles qui n'en
coûtent pas, sont sur [Soutenir le projet](./support.md).

Vous cherchez plutôt le classement des makers ? C'est la [TigerSquad](./tigersquad.md)
— des niveaux et des XP pour tous ceux qui la rejoignent.
