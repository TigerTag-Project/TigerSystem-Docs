# Bambu Lab série A1 : passer en mode LAN

Pour les A1 mini, A1 et A2L — activez **le mode LAN Only** et **le mode Développeur** sur
l'imprimante elle-même, puis ajoutez-la dans Tiger Studio avec son adresse IP, son numéro de série
et son code d'accès. Voir [Compatibilité Bambu Lab](../compatibility/bambu-lab.md) pour les autres
séries et l'option cloud.

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step1.jpg" alt="Série A1 — page Réglages" />
<p><strong>Étape 1.</strong> Activez le mode LAN Only côté imprimante. Ouvrez la page Réglages depuis l'écran de l'imprimante en touchant Réglages.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step2.jpg" alt="Série A1 — entrée LAN Only Mode" />
<p>Appuyez sur « LAN Only Mode ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step3.jpg" alt="Série A1 — activation du mode LAN Only" />
<p>Activez « LAN Only Mode ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step4.jpg" alt="Série A1 — entrée mode Développeur" />
<p><strong>Étape 2.</strong> Activez le mode Développeur côté imprimante. Activez « Developer Mode ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step5.jpg" alt="Série A1 — Avis important" />
<p>Lisez attentivement l'Avis Important. Si vous acceptez tous les risques et conséquences associés, cochez « I confirm reading and understanding the Important Notice above » puis sélectionnez « Enable ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step6.jpg" alt="Série A1 — mode Développeur activé" />
<p>Une fois la fonction activée, le bouton devient vert.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step7.jpg" alt="Série A1 — adresse IP et numéro de série" />
<p>Relevez l'adresse IP et le numéro de série depuis les paramètres de l'imprimante.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step8.jpg" alt="Série A1 — ajout de l'imprimante dans Tiger Studio" />
<p>Utilisez l'adresse IP, le numéro de série et le code d'accès dans Tiger Studio.</p>
</div>
