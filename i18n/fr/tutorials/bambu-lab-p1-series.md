# Bambu Lab série P1 : passer en mode LAN

Pour les P1P et P1S — activez **le mode LAN Only** et **le mode Développeur** sur l'imprimante
elle-même, puis ajoutez-la dans Tiger Studio avec son adresse IP, son numéro de série et son code
d'accès. Voir [Compatibilité Bambu Lab](../compatibility/bambu-lab.md) pour les autres séries et
l'option cloud.

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step1.jpg" alt="Série P1 — Réglages, WLAN" />
<p><strong>Étape 1.</strong> Activez le mode LAN Only côté imprimante. Ouvrez la page Réglages et sélectionnez WLAN.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step2.jpg" alt="Série P1 — sélection du mode LAN Only" />
<p>Sélectionnez le mode LAN Only.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step3.jpg" alt="Série P1 — confirmation du mode LAN Only" />
<p>Sélectionnez Oui pour activer le mode LAN Only.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step4.jpg" alt="Série P1 — mode LAN Only activé" />
<p>Une fois le mode LAN Only activé, ON s'affiche.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step5.jpg" alt="Série P1 — accès au mode Développeur" />
<p><strong>Étape 2.</strong> Activez le mode Développeur côté imprimante. Après avoir activé le mode LAN Only, faites défiler vers le bas et trouvez Developer Mode.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step6.jpg" alt="Série P1 — Avis important" />
<p>Sélectionnez Developer Mode et lisez attentivement l'Avis Important.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step7.jpg" alt="Série P1 — activation du mode Développeur" />
<p>Si vous acceptez tous les risques et conséquences, faites défiler jusqu'en bas et appuyez sur Enable.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step8.jpg" alt="Série P1 — mode Développeur activé" />
<p>Une fois Developer Mode activé, ON s'affiche. Utilisez ensuite l'adresse IP, le numéro de série et le code d'accès dans Tiger Studio.</p>
</div>
