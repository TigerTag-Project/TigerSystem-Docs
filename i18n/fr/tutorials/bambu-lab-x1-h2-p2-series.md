# Bambu Lab série X1 / X1E / H2 / P2 : passer en mode LAN

Pour les P2S, X1 Carbon, X1E, X2D, H2S, H2D, H2D Pro et H2C — activez **le mode LAN Only** et **le mode
Développeur** sur l'imprimante elle-même, puis ajoutez-la dans Tiger Studio avec son adresse IP,
son numéro de série et son code d'accès. Voir [Compatibilité Bambu Lab](../compatibility/bambu-lab.md)
pour les autres séries et l'option cloud.

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step1.jpg" alt="Série X1 — page Réglages" />
<p><strong>Étape 1.</strong> Activez le mode LAN Only côté imprimante. Ouvrez la page Paramètres depuis le côté gauche de l'écran de l'imprimante et appuyez sur Paramètres.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step2.jpg" alt="Série X1 — entrée LAN Only" />
<p>Appuyez sur « LAN Only ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step3.png" alt="Série X1 — activation du mode LAN Only" />
<p>Activez le mode LAN Only.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step4.png" alt="Série X1 — aperçu en direct du mode LAN" />
<p>Choisissez d'activer ou non l'aperçu en direct du mode LAN selon vos besoins.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step5.jpg" alt="Série X1 — entrée mode Développeur" />
<p><strong>Étape 2.</strong> Activez le mode Développeur côté imprimante. Activez « Developer Mode ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step6.png" alt="Série X1 — Avis important et avertissement de risque" />
<p>Lisez attentivement l'Avis Important et l'avertissement de risque. Si vous acceptez tous les risques et conséquences associés, cochez « I confirm reading and understanding the Important Notice above » puis sélectionnez « Enable Developer Mode ».</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/x1/x_series_step7.png" alt="Série X1 — mode Développeur activé" />
<p>Une fois la fonction activée, le bouton devient vert. Utilisez ensuite l'adresse IP, le numéro de série et le code d'accès dans Tiger Studio.</p>
</div>
