# Elegoo Centauri Carbon 2 : passer en mode LAN

Le lien direct de Tiger Studio nécessite d'activer **le mode LAN Only** sur l'imprimante
elle-même — une configuration ponctuelle, à l'écran. Voir
[Compatibilité Elegoo](../compatibility/elegoo.md) pour le reste de l'intégration.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — écran LAN Only" />
<p>Sur l'écran tactile, sélectionnez Paramètres → LAN Only. Activez LAN Only + Code d'accès puis sélectionnez Confirmer.</p>
</div>
