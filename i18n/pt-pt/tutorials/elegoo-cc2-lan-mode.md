# Elegoo Centauri Carbon 2: mudar para o modo LAN

A ligação direta do Tiger Studio exige que o **modo LAN Only** esteja ativado na própria impressora — uma configuração única, feita no ecrã. Consulte a [compatibilidade com a Elegoo](../compatibility/elegoo.md) para o resto da integração.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — ecrã LAN Only" />
<p>No ecrã tátil, selecione Definições → LAN Only. Ative LAN Only + Access Code e selecione Confirm.</p>
</div>
