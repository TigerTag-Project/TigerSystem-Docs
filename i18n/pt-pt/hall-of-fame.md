# Galeria da Fama

Uma norma não é escrita por uma empresa. É escrita por quem aparece.

Todos os que estão abaixo abriram uma issue, enviaram um pull request ou escreveram código num dos [repositórios TigerTag](./developers/repositories.md). Uns corrigiram uma gralha. Outros reescreveram uma página. Outros comunicaram um erro de forma tão precisa que foi corrigido no mesmo dia. Tudo conta, e tudo está aqui — comunicar um problema é uma contribuição, não uma queixa.

## Junte-se à luta

Não há candidatura, nem formulário, nem aprovação. Faça qualquer uma destas coisas e o seu nome aparece nesta página da próxima vez que a lista for atualizada:

| | |
|---|---|
| **Abrir uma issue** | Algo errado, pouco claro ou em falta — na documentação, numa aplicação, no protocolo. Um relatório preciso vale mais do que um educado. |
| **Enviar um pull request** | Um assunto de cada vez, na página que lhe pertence. O [CONTRIBUTING](../CONTRIBUTING.md) tem as regras; são curtas. |
| **Traduzir** | O inglês é a fonte, o francês é derivado. Uma nova língua começa com uma única página. |
| **Construir algo compatível** | Um leitor, uma aplicação, uma integração de impressora, uma caixa para imprimir. Diga *«compatível com o TigerTag»* livremente — sem autorização, sem taxa. |
| **Parti-lo e contar-nos** | Chip, leitor, versão da aplicação, o que fez, o que mostrou. Esse é o relatório que é corrigido. |

Outras formas de ajudar, incluindo as que custam dinheiro e as que não custam nada, estão em [Apoiar o projeto](./support.md).

À procura, em vez disso, do ranking dos makers? Esse é o [TigerSquad](./tigersquad.md) — níveis e XP para todos os que aderem.
