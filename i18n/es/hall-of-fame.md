# Salón de la fama

Un estándar no lo escribe una empresa. Lo escribe quien da un paso al frente.

Todos los de abajo abrieron una issue, enviaron una pull request o escribieron
código en alguno de los [repositorios de TigerTag](./developers/repositories.md).
Algunos corrigieron una errata. Algunos reescribieron una página. Algunos
informaron de un fallo con tanta precisión que se arregló el mismo día. Todo
cuenta, y todo está aquí: informar de un problema es una contribución, no una
queja.

## Únete a la lucha

No hay solicitud, ni formulario, ni aprobación. Haz una cualquiera de estas cosas
y tu nombre aparecerá en esta página la próxima vez que se actualice la lista:

| | |
|---|---|
| **Abre una issue** | Algo mal, poco claro o que falta: en la documentación, en una aplicación, en el protocolo. Un informe preciso vale más que uno educado. |
| **Envía una pull request** | Un tema cada vez, en la página a la que pertenece. [CONTRIBUTING](../CONTRIBUTING.md) tiene las reglas; son breves. |
| **Traduce** | El inglés es la fuente, el francés se deriva de él. Un idioma nuevo empieza con una sola página. |
| **Construye algo compatible** | Un lector, una aplicación, una integración con una impresora, una carcasa para imprimir. Di *«compatible con TigerTag»* con libertad: sin permiso, sin tasa. |
| **Rómpelo y cuéntanoslo** | Chip, lector, versión de la aplicación, lo que hiciste, lo que mostró. Ese es el informe que se arregla. |

Otras formas de ayudar, incluidas las que cuestan dinero y las que no cuestan nada,
están en [Apoya el proyecto](./support.md).

¿Buscas más bien el ranking de makers? Esa es la [TigerSquad](./tigersquad.md):
niveles y XP para todos los que se unen.
