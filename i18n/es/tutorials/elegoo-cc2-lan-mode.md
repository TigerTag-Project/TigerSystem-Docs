# Elegoo Centauri Carbon 2: pasar al modo LAN

El enlace directo de Tiger Studio necesita el **modo LAN Only** activado en la propia
impresora: una configuración única, en pantalla. Consulta la [compatibilidad con Elegoo](../compatibility/elegoo.md) para el resto de la
integración.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — pantalla LAN Only" />
<p>En la pantalla táctil, selecciona Settings → LAN Only. Activa LAN Only + Access Code y selecciona Confirm.</p>
</div>
