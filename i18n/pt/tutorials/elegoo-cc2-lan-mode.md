# Elegoo Centauri Carbon 2: ative o modo LAN

A conexão direta do Tiger Studio exige que o **modo LAN Only** esteja ativado na própria impressora — uma configuração única, feita na tela. Veja [Compatibilidade com Elegoo](../compatibility/elegoo.md) para o restante da
integração.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — tela LAN Only" />
<p>Na tela sensível ao toque, selecione Settings → LAN Only. Ative LAN Only + Access Code e selecione Confirm.</p>
</div>
