Nomenclatura: as marcas **TigerTag** levam a lettering TIGER TAG; as marcas só com a cabeça são
ativos **Tiger**. Cada família de insígnias vem em três recortes — quadrado, contido,
transbordante — e é a arte exata impressa nas caixas dos parceiros. As marcas brancas são
vetores de cor única para superfícies escuras; as marcas de **contorno** pretas são sempre
para fundos claros. Os **ícones do aplicativo TigerSystem** levam o próprio fundo
escuro.

## TigerScale

|| |
|---|---|
| <img src="../assets/tigerscale-v3.webp" alt="TigerScale V3 — tela sensível ao toque colorida, dois leitores NFC PN532" /> | <img src="../assets/tigerscale-at-home.jpg" alt="Uma TigerScale V3 na bancada de um maker, com uma bobina apoiada" /> |

A **TigerScale V3**, a geração atual: a foto do produto e uma
**ilustração** da mesma balança na bancada de um maker — a segunda é um
render, não uma fotografia, então identifique-a como tal se for publicá-la.
ESP32-S3, tela sensível ao toque colorida de 3,5″, dois leitores PN532 para que uma
[bobina com tag dupla](../concepts/tigertag-chip.md) seja identificada não importa de que lado
seja apoiada. Hardware aberto, MIT.

As gerações anteriores estão documentadas na [página do produto](../products/tigerscale.md);
a foto mais antiga, [`tigerscale-photo.jpg`](../assets/tigerscale-photo.jpg), é
mantida só para uso de arquivo — por favor, não a use para ilustrar o produto
hoje.
