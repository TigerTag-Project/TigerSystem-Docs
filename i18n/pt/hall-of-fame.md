# Hall da Fama

Um padrão não é escrito por uma empresa. É escrito por quem aparece.

Todos os abaixo abriram uma issue, enviaram um pull request ou escreveram código em um dos
[repositórios do TigerTag](./developers/repositories.md). Alguns corrigiram um erro de digitação. Alguns
reescreveram uma página. Alguns relataram um bug com tanta precisão que ele foi corrigido no mesmo
dia. Tudo conta, e tudo está aqui — relatar um problema é uma
contribuição, não uma reclamação.

## Junte-se à luta

Não há inscrição, formulário nem aprovação. Faça qualquer uma destas coisas e o seu
nome aparece nesta página na próxima vez que a lista for atualizada:

| | |
|---|---|
| **Abra uma issue** | Algo errado, confuso ou faltando — na documentação, em um aplicativo, no protocolo. Um relato preciso vale mais do que um educado. |
| **Envie um pull request** | Um assunto por vez, na página que é dona dele. O [CONTRIBUTING](../CONTRIBUTING.md) traz as regras; são curtas. |
| **Traduza** | O inglês é a fonte, o francês é derivado. Um novo idioma começa com uma única página. |
| **Construa algo compatível** | Um leitor, um aplicativo, uma integração de impressora, uma carcaça para imprimir. Diga *"compatível com o TigerTag"* livremente — sem permissão, sem taxa. |
| **Quebre e conte para nós** | Chip, leitor, versão do aplicativo, o que você fez, o que apareceu. Esse é o relato que é corrigido. |

Outras formas de ajudar, inclusive as que custam dinheiro e as que não custam
nada, estão em [Apoie o projeto](./support.md).

Procurando o ranking dos makers? Esse é o [TigerSquad](./tigersquad.md)
— níveis e XP para todos que entram.
