# Hall of Fame

Standardu nie pisze firma. Piszą go ci, którzy się pojawiają.

Każda osoba poniżej otworzyła issue, wysłała pull request albo napisała kod w jednym z
[repozytoriów TigerTag](./developers/repositories.md). Niektórzy poprawili literówkę. Niektórzy
przepisali stronę. Niektórzy zgłosili błąd tak precyzyjnie, że naprawiono go tego samego
dnia. Wszystko się liczy i wszystko jest tutaj — zgłoszenie problemu to
wkład, a nie narzekanie.

## Dołącz do walki

Nie ma zgłoszenia, formularza ani zatwierdzania. Zrób dowolną z tych rzeczy, a twoje
imię trafi na tę stronę przy następnym odświeżeniu listy:

| | |
|---|---|
| **Otwórz issue** | Coś jest złe, niejasne lub brakuje — w dokumentacji, aplikacji, protokole. Precyzyjne zgłoszenie jest warte więcej niż uprzejme. |
| **Wyślij pull request** | Jeden temat naraz, na stronie, która go dotyczy. [CONTRIBUTING](../CONTRIBUTING.md) zawiera zasady; są krótkie. |
| **Tłumacz** | Angielski jest źródłem, francuski jest pochodny. Nowy język zaczyna się od jednej strony. |
| **Zbuduj coś zgodnego** | Czytnik, aplikację, integrację z drukarką, obudowę do wydruku. Mów swobodnie *„zgodny z TigerTag”* — bez pozwolenia, bez opłat. |
| **Zepsuj to i daj nam znać** | Chip, czytnik, wersja aplikacji, co zrobiono, co się pokazało. Takie zgłoszenie zostaje naprawione. |

Inne sposoby pomocy, zarówno te, które kosztują pieniądze, jak i te, które nie kosztują
nic, są na stronie [Wesprzyj projekt](./support.md).

Szukasz zamiast tego rankingu twórców? To [TigerSquad](./tigersquad.md)
— poziomy i XP dla każdego, kto dołącza.
