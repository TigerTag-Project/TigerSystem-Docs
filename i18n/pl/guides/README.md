# Przewodniki

Krótkie instrukcje ukierunkowane na zadanie (bardziej zwięzłe i celowane niż
[poradniki](../tutorials/README.md)).

## Dostępne

- **[Start za 0 $](./start-for-free.md)** — dlaczego widoczne
  części są najmniejszą częścią i co już masz, co zastępuje
  wszystko, co wygląda na obowiązkowe.
- **[Gdy dwa chipy szpuli odczytują się jako dwie szpule](./twin-tag-pair.md)** — jeden
  test, który to rozstrzyga, dlaczego dwa osobne zapisy nigdy nie stworzą
  pary i jak przepisać oba chipy jako jedną.
- **[Połącz asystenta AI ze swoim kontem](./connect-an-ai-assistant.md)** —
  pozwól Claude, ChatGPT lub dowolnemu klientowi MCP czytać twoje szpule, regały i drukarki
  oraz odetnij go od konta.
