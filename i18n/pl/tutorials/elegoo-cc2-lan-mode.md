# Elegoo Centauri Carbon 2: przełączenie na tryb LAN

Bezpośrednie połączenie Tiger Studio wymaga włączenia **trybu LAN Only** na samej drukarce — to jednorazowa konfiguracja na ekranie. Resztę integracji opisuje strona [Zgodność z Elegoo](../compatibility/elegoo.md).

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — ekran LAN Only" />
<p>Na ekranie dotykowym wybierz Settings → LAN Only. Włącz LAN Only + Access Code i wybierz Confirm.</p>
</div>
