# Elegoo Centauri Carbon 2: passare alla modalità LAN

Il collegamento diretto di Tiger Studio richiede che la **modalità LAN Only** sia attivata sulla
stampante stessa — una configurazione una tantum, direttamente sullo schermo. Per il resto
dell'integrazione consulta [Compatibilità Elegoo](../compatibility/elegoo.md).

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — schermata LAN Only" />
<p>Sul touchscreen, seleziona Impostazioni → LAN Only. Attiva LAN Only + Access Code e seleziona Conferma.</p>
</div>
