# Elegoo Centauri Carbon 2: switch to LAN mode

Tiger Studio's direct link needs **LAN Only mode** enabled on the printer itself — a one-time,
on-screen setup. See [Elegoo compatibility](../compatibility/elegoo.md) for the rest of the
integration.

<div class="ts-tuto-step">
<img src="../assets/elegoo-lan-mode/steps/elegoo_lan_only.jpg" alt="Centauri Carbon 2 — LAN Only screen" />
<p>On the touch screen, select Settings → LAN Only. Enable LAN Only + Access Code and select Confirm.</p>
</div>
