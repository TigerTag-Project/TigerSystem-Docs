# Bambu Lab A1 series: switch to LAN mode

For the A1 mini, A1 and A2L — enable **LAN Only Mode** and **Developer Mode** on the printer
itself, then add it in Tiger Studio with its IP address, serial number and access code. See
[Bambu Lab compatibility](../compatibility/bambu-lab.md) for the other series and the cloud option.

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step1.jpg" alt="A1 series — Setting page" />
<p><strong>Step 1.</strong> Enable LAN Only Mode on the printer side. Enter the Setting page from the printer screen by clicking Setting.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step2.jpg" alt="A1 series — LAN Only Mode entry" />
<p>Click "LAN Only Mode".</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step3.jpg" alt="A1 series — enabling LAN Only Mode" />
<p>Enable "LAN Only Mode".</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step4.jpg" alt="A1 series — Developer Mode entry" />
<p><strong>Step 2.</strong> Enable Developer Mode on the printer side. Enable "Developer Mode".</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step5.jpg" alt="A1 series — Important Notice" />
<p>Please carefully read the Important Notice. If you accept all related risks or consequences, check "I confirm reading and understanding the Important Notice above" and then select "Enable".</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step6.jpg" alt="A1 series — Developer Mode enabled" />
<p>Once this feature is enabled, the button will turn green.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step7.jpg" alt="A1 series — printer IP and serial number" />
<p>Check the printer IP address and Serial Number from the printer settings.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/a1/a_series_step8.jpg" alt="A1 series — adding the printer in Tiger Studio" />
<p>Use the printer IP address, Serial Number and Access Code in Tiger Studio.</p>
</div>
