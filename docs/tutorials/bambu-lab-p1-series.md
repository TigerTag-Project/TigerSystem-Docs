# Bambu Lab P1 series: switch to LAN mode

For the P1P and P1S — enable **LAN Only mode** and **Developer Mode** on the printer itself, then
add it in Tiger Studio with its IP address, serial number and access code. See
[Bambu Lab compatibility](../compatibility/bambu-lab.md) for the other series and the cloud option.

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step1.jpg" alt="P1 series — Settings, WLAN" />
<p><strong>Step 1.</strong> Enable LAN Only mode on the printer side. Enter the Settings page and select WLAN.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step2.jpg" alt="P1 series — selecting LAN Only mode" />
<p>Select LAN Only mode.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step3.jpg" alt="P1 series — confirming LAN Only mode" />
<p>Select Yes, and enable LAN Only mode.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step4.jpg" alt="P1 series — LAN Only mode ON" />
<p>After enabling LAN Only mode, ON will be displayed.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step5.jpg" alt="P1 series — finding Developer Mode" />
<p><strong>Step 2.</strong> Enable Developer mode on the printer side. After turning on LAN Only mode, click the Scroll Down button and find Developer Mode.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step6.jpg" alt="P1 series — Important Notice" />
<p>Select Developer Mode, and please read the Important Notice carefully.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step7.jpg" alt="P1 series — enabling Developer Mode" />
<p>If you accept all related risks or consequences, scroll down to the end and click Enable.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/bambu-lab-lan-mode/p1/p1_series_step8.jpg" alt="P1 series — Developer Mode ON" />
<p>After enabling Developer Mode, ON will be displayed. Then use the printer IP address, Serial Number and Access Code in Tiger Studio.</p>
</div>
