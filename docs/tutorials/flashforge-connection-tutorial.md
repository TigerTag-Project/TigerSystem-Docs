# FlashForge: connection tutorial

FlashForge printers connect over your local network only — there is no cloud
option. What you need from the touchscreen depends on how Tiger Studio finds the
printer:

- **Found by the network scan:** the **Printer ID** only — step 3.
- **Added by hand:** the **serial number** and **IP address** (step 2), plus the
 **Printer ID** (step 3).

See [FlashForge compatibility](../compatibility/flashforge.md) for the rest of
the integration.

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step1.jpg" alt="FlashForge touchscreen — Basic Info button" />
<p><strong>Step 1.</strong> On the main interface, tap the "Basic Info" button at the bottom right of the screen.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step2.jpg" alt="FlashForge touchscreen — Basic Info page" />
<p><strong>Step 2.</strong> In the Basic Info page, retrieve the Serial No. and the IP Address.</p>
</div>

<div class="ts-tuto-step">
<img src="../assets/flashforge-connection-tutorial/steps/ffg_step3.jpg" alt="FlashForge touchscreen — Network Mode page" />
<p><strong>Step 3.</strong> Select the gear icon, tap "Network Mode", then retrieve the Printer ID.</p>
</div>

> **One value, two names.** The printer calls it *Printer ID*; Tiger Studio's
> form calls it **Password**. The Printer ID is what you type there.
